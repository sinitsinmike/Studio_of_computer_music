# Студия компьютерной музыки — ДМШ им. Н. П. Ракова

Статический адаптивный сайт на HTML, CSS и JavaScript для публикации на GitHub Pages.

## Страницы
- `index.html` — описание студии, цели и направления обучения.
- `literature.html` — список литературы и интернет-ресурсов.
- `software.html` — каталог музыкальных программ с поиском и фильтрами.
- `lessons.html` — список PDF-уроков с шаблонами кнопок «Открыть» и «Скачать».

## Локальный просмотр
Откройте `index.html` в браузере. Для локальной проверки также можно запустить простой сервер из корня папки:

```bash
python3 -m http.server 8000
```

Затем откройте `http://localhost:8000`.

## Публикация через GitHub Pages
1. Создайте новый репозиторий на GitHub.
2. Загрузите содержимое этой папки в корень репозитория.
3. Откройте **Settings → Pages**.
4. В разделе сборки выберите **Deploy from a branch**.
5. Выберите ветку `main` и папку `/ (root)`, затем сохраните настройки.
6. После публикации сайт будет доступен по адресу вида `https://USERNAME.github.io/REPOSITORY/`.

Сайт не использует серверную часть и базу данных. Внешние ссылки открывают официальные сайты разработчиков.

## Как добавить PDF-урок
1. Поместите PDF в `documents/lessons/`, например `lesson-01.pdf`.
2. В `lessons.html` замените карточку нужного урока и добавьте ссылки:

```html
<a class="button primary" href="documents/lessons/lesson-01.pdf" target="_blank" rel="noopener">Открыть PDF</a>
<a class="button secondary" href="documents/lessons/lesson-01.pdf" download>Скачать PDF</a>
```

3. Укажите название и описание урока.
4. Сохраните изменения и отправьте их в репозиторий.

## Как добавить изображения
Поместите изображения в `assets/images/` и используйте относительные пути, например `assets/images/classroom.jpg`.

## Примечания
- Каталог программ — начальная подборка; доступность и лицензии следует перепроверять перед использованием.
- В `lessons.html` пока стоят три демонстрационные карточки без PDF-файлов.
- В каталоге литературы представлены некоторые источники из учебной программы; список можно расширять.
