# Студия компьютерной музыки — ДМШ им. Н. П. Ракова

Статический адаптивный сайт на HTML, CSS и JavaScript для публикации через GitHub Pages.

## Страницы сайта

- `index.html` — главная страница и описание студии.
- `lessons.html` — список уроков и ссылки на PDF.
- `literature.html` — литература и учебные материалы.
- `software.html` — каталог музыкальных программ.
- `assets/` — изображения, CSS и JavaScript.

## Где хранить PDF-файлы

В текущем репозитории используются две папки в корне проекта:

- `PDF/` — PDF-файлы уроков и шпаргалки к урокам.
- `DOCS/` — книги, руководства и другие справочные материалы.

**Новые PDF-уроки загружайте в папку `PDF/`.**  
Материалы по Logic Pro и другие книги/руководства загружайте в `DOCS/`.

Старайтесь давать файлам понятные имена, например:

- `Урок 7.pdf`
- `Урок 8.pdf`
- `Шпаргалка к уроку 7.pdf`

Чтобы ссылки работали на GitHub Pages, сохраняйте файлы в репозитории и учитывайте точное имя файла, включая пробелы, буквы и расширение `.pdf`.

## Как добавить следующий урок на сайт

**Важно: если просто загрузить новый PDF в `PDF/`, карточка и кнопки на странице автоматически не появятся.** Сейчас список уроков задаётся вручную в `lessons.html`; GitHub Pages не предоставляет странице автоматический список файлов в папке.

После загрузки, например, `Урок 7.pdf`:

1. Откройте `lessons.html` в GitHub и нажмите кнопку редактирования.
2. Скопируйте HTML-код карточки предыдущего урока.
3. В копии измените номер, название и описание на данные урока 7.
4. Укажите путь к PDF в обеих кнопках — «Открыть PDF» и «Скачать PDF».
5. Сохраните изменения через **Commit changes**.

Пример ссылок для файла `PDF/Урок 7.pdf`:

```html
<a class="button primary" href="PDF/Урок%207.pdf" target="_blank" rel="noopener">Открыть PDF</a>
<a class="button secondary" href="PDF/Урок%207.pdf" download>Скачать PDF</a>
```

В URL пробел в имени файла записан как `%20`. Если имя файла отличается, укажите его фактическое имя. После сохранения GitHub Pages опубликует обновление автоматически, обычно через короткое время.

## Как добавить материал в раздел литературы

1. Загрузите PDF в `DOCS/`.
2. Откройте `literature.html`.
3. Добавьте карточку или ссылку на новый файл, используя его путь, например `DOCS/Logic Pro X 10 микшер.pdf`.
4. Сохраните изменения через **Commit changes**.

Загрузка файла в `DOCS/` сама по себе не добавляет ссылку на него на страницу литературы — её также нужно прописать в `literature.html`.

## Локальный просмотр

Откройте `index.html` в браузере. Для проверки через локальный сервер запустите команду из корня папки проекта:

```bash
python3 -m http.server 8000
```

Затем откройте `http://localhost:8000`.

## Публикация через GitHub Pages

1. Загрузите файлы сайта в корень репозитория.
2. Откройте **Settings → Pages**.
3. В разделе сборки выберите **Deploy from a branch**.
4. Выберите ветку `main` и папку `/ (root)`, затем сохраните настройки.
5. После публикации сайт будет доступен по адресу вида `https://USERNAME.github.io/REPOSITORY/`.

Сайт статический: серверной части и базы данных нет. Для появления новых карточек уроков и материалов нужно обновлять соответствующие HTML-файлы, если не будет отдельно реализована автоматическая генерация списка.

## Изображения

Помещайте изображения в `assets/images/` и используйте относительные пути, например `assets/images/classroom.jpg`.
